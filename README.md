# 📚 Estudos de Programação em C/C++ — FATEC Lins

Repositório dedicado aos exercícios e atividades práticas desenvolvidos durante minha graduação em **Análise e Desenvolvimento de Sistemas na FATEC Lins**, com previsão de conclusão em julho de 2029.

## 🎯 Objetivo

Registrar minha evolução em lógica de programação, algoritmos e fundamentos das linguagens C e C++, aplicando os conhecimentos adquiridos durante a graduação.

## 💻 Conteúdos estudados

- Entrada e saída de dados
- Variáveis e tipos de dados
- Operações aritméticas
- Cálculo de médias e porcentagens
- Exercícios de lógica de programação

## 🛠️ Ferramentas

- Visual Studio Code
- Embarcadero Dev-C++
- GCC / G++ (MSYS2)
- Git e GitHub

## 📈 Evolução

Este repositório será atualizado conforme avanço nos estudos, com novos exercícios e melhorias nos códigos existentes.
